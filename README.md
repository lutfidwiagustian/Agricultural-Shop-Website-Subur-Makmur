# SUBUR MAKMUR Agriculture & Cattle

An integrated e-commerce and business portal web application built for agricultural supply stores and livestock trading. This platform connects upstream farming production supplies with downstream harvest and livestock trading.

## 🌟 Key Features

- **Upstream Production Catalog:** Comprehensive product browsing for seeds, hybrid corn, herbicides (Bablas, Gramaxone, Roundup), pesticides, fertilizers, and general household essentials.
- **Advanced Search & Filter:** Instant category switching and real-time product searching.
- **Downstream Trading Services:** Dedicated submission forms for farmers to sell harvested crops (rice/grain, corn) and livestock (cattle, goats).
- **Interactive Shopping Cart:** Fully functional cart system with item quantity management (+/-), subtotal calculations, and persistent state.
- **Direct WhatsApp Integration:** Seamless checkout and inquiry formatting sent directly to the store admin via WhatsApp (optimized for both desktop and mobile history navigation).
- **Educational & Tutorial Hub:** Practical guides on chemical dosages, seed treatments, and molasses fermentation for livestock feed.

---

## 🛠️ Tech Stack

- **HTML5 & Semantic Markup**
- **Tailwind CSS** (via CDN for rapid styling and custom configuration)
- **Vanilla JavaScript (ES6+)** for reactive UI rendering, state management, and history API handling.
- **FontAwesome & Google Fonts (Inter)** for UI elements and typography.
